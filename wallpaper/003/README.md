# NEON HEART CITY V2 · 高清美术重制版

## 直接运行

1. **完整解压 ZIP**，保留全部目录结构。
2. 双击 `index.html`，在 Chrome / Edge / Firefox 中打开。无需互联网，无需 Python，无需 localhost。
3. 右下角齿轮打开设置面板。可调整风速、粒子密度、鼠标推力、窗光、亮度、饱和度、景深和视差。
4. 鼠标移动会影响附近光点与爱心的方向、速度和分布。壁纸没有眨眼动画。

## 改版说明

V1 的人物采用简化矢量绘制，与高细节参考图存在显著风格及精细度差距。本版换用**重新生成的高细节人物与城市插画**，保留黑紫色双马尾、红粉色眼睛、蝴蝶结、哥特上衣、渔网袜、黑紫条纹袜、厚底系带靴、紫粉霓虹、夜间未来城市等视觉元素；删除美术图里静态的假设置面板，换成真正可折叠的网页控件。

## 资源与结构

- `index.html`：仅承载网页与 UI 结构，不包含图像帧坐标表。
- `css/wallpaper.css`：布局、色彩、景深滤镜及面板样式。
- `js/player.js`：requestAnimationFrame 播放、图层加载、窗光、交互粒子和参数逻辑。
- `config/config.json`：标准 JSON 动画资源数据包（图层名称、素材路径、坐标、尺寸、Z 顺序、动画帧率、相位与默认参数）。
- `config/config.js`：同一份数据的离线脚本版本，避免 `file://` 对 `fetch()` 的限制。
- `assets/background/city_4k.png`：3840×2160 的独立 PNG 夜景底图，不做预先景深模糊。
- `assets/body/character.png`：人物主体透明 PNG。
- `assets/hair_left/`、`assets/hair_right/`、`assets/hair_other/`：各 48 张连续编号透明 PNG，分组预渲染帧。
- `assets/particles/`：爱心、闪光、光球 PNG 透明图。
- `assets/art/scene_clean_source.png`：重制插画源画面，用于重新导出分层素材。
- `tools/export_frames.py`：可选的 PNG 分层帧重建脚本（Python + Pillow + NumPy + OpenCV，不影响直接打开网页）。
- `docs/`：实际浏览器合成截图、说明及自动检查结果。

## 质量与技术边界（重要）

- 网页布局、城市底图支持 3840×2160 输出，但新生成插画**初始绘制尺寸为 1672×941**，4K 背景是高质量重采样，而非真正逐像素原生 4K 绘制。
- 双马尾和刘海使用**从重制插画分层后的算法预渲染**独立 RGBA PNG 帧，运行时只切帧播放，不做实时骨骼拉扯、不做相邻图片的交叉淡入。它们不是 144 幅逐帧单独手绘的插画。
- 重制插画最初是合成图；虽然已经拆分图层，遮挡区背后的楼群由其他城市画面片段重建，**不等同于从零独立绘制的全景无人物背景**。在大幅修改发束轮廓或较高视差时可能需要重新绘制被遮挡背景。
- 上述三点意味着该版本解决了主要的**视觉质量差距**，但不能被视为完全满足“所有原画及逐帧动画都原生手绘、4K 级无瑕独立分层”的严格制作规范。

## 动画

- 左侧头发：48 帧，16FPS，循环约 3 秒；发梢位移较大、发根缓慢固定。
- 右侧头发：48 帧，16FPS，独立相位；发根稳定。
- 面部细发束：48 帧，16FPS，小幅度浮动，不眨眼。
- 总计 144 张发丝运动 PNG。循环从帧 47 返回帧 0，无透明度交叉淡入。
- 背景与人物被统一平移，以防遮挡区域出现明显的景深裂缝。霓虹与粒子提供附加深度感。

## 后续修改

- 动画默认值：`config/config.json` / `config/config.js` 的 `defaults`；两个文件保持一致。
- 调整图层的位置、fps、播放相位：在两个配置文件的 `layers` 中修改相应字段。
- 更换角色：替换 `assets/body/character.png` 和三个头发文件夹的逐帧 PNG，并同步更新边界与画面比例。
- 运行时资源无需跨域通信，无第三方字体、CDN、在线动画插件或外部 API。
